# Morning phase takes only what recharges

A stated principle, captured 2026-08-13:

> Core principle of mine: only wellness in morning phase, only things that recharge me.

## What it would mean in zenborg

The MORNING phase is not a neutral time band — it carries a rule about *what kind* of moment may be planted there. Wellness-tagged habits (Mindfulness, Fitness, Nutrition) are welcome; craft/work moments are not.

Open questions this raises:

- Is this a **phase config** property (a declared admissible-tag set per phase), or guidance the planning skills honour without enforcement?
- Does it bind `week-planning` — should the Monday allocation refuse to place a `#build` moment in MORNING?
- How does it interact with the existing "3 per phase" day-view display limit?

The lightest version is guidance in `week-planning` + `cycle-planning`. The strongest is a phase-level invariant the allocation tools enforce, which would be the first content-based constraint zenborg puts on a phase.
