# Keel — postmortem

**Born:** 2026-02-22 · **Retired:** 2026-08-28 · **334 commits**

Named for a boat's stabilizing fin — near-homophone of equanimity (Pāli
*upekkhā*). The premise: *"See where your attention goes — and steer it
from compulsion toward flourishing."*

---

## What it shipped

Three surfaces observing three channels of attention:

| Surface | Channel | What it did |
|---|---|---|
| **agent** (`apps/agent`) | Claude Code sessions | Activity-log writer, fences, gap practice |
| **browser** (`apps/browser`) | Chrome | Watchlist sensors, blocklist drogue, activity writer |
| **desktop** (`apps/desktop`) | macOS frontmost app | "Attention compass" — Tauri + React + fp-ts, 4750 LOC |

Plus a **tray** writer (replaced desktop) and three **launchd agents** for
garmin sync, classify, and tray uptime.

## Why it merged

Two forces converged:

**1. The intervention thesis failed.** Keel was built to *steer* attention —
shields that blocked sites, budgets that rationed time, signals that nudged.
Every one was retired by mid-2026 after research review showed static
interventions increase workload for high-perceived-control users. What survived
was the *observation* layer: the log, the watchlist, the fences that read
accumulated signal rather than enforcing static rules. Keel stopped being a
product and became infrastructure.

**2. Zenborg needed what keel observed.** The kairos-direction pivot
(2026-08-03) recognized that zenborg's garden — "where will I place my
consciousness today?" — demands the raw attention signal keel produces. Rafa
stopped using zenborg because *the tool demands input it should derive*. The
log is that derivation source. Two repos for one pipeline was indirection.

The tray's uptime data sealed it: dark for 1096 of 1342 hours tracked, with
670 hours of machine-in-use time lost across 55 gaps. The writer needed a
process that stays up, and zenborg already was that process.

## What we kept

| Concept | Where it lives now |
|---|---|
| Activity log (append-only JSONL, 4 streams) | `~/.kairos/keel/log/` — same path, zenborg writes it |
| Plugin (hooks, fences, gap practice) | `zenborg/plugin/` — registered as kairos Claude Code plugin |
| Observer domain (`domain.rs`) | `src-tauri/crates/observer-core/` — byte-for-byte |
| Watchlist (observe + windowed tiers) | `~/.kairos/keel/config.json` — same schema |
| Blocklist drogue | Browser extension (still in kairos, Phase D2) |
| Privacy posture | Local-first, logs never leave the machine |
| The name "keel" | `~/.kairos/keel/` subtree — the attention namespace inside the vault |

## What we learned

**Observation is the product; intervention is a trap.** Every intervention keel
shipped was retired within four months. The log outlived all of them. Building
for "steering" led to walls the user resented; building for "seeing" led to
data the garden can metabolize. The fences that survived are the ones that read
the data, not the ones that read a config.

**Uptime is an architecture problem, not a daemon problem.** Three launchd
plists, a menubar tray, and a browser extension were four separate answers to
"how does this stay running." The real answer was: be part of the app the user
already runs. One process, one log.

**Separate repos for coupled systems create drift.** Keel and zenborg shared a
vault, a substrate contract, and a user. Two repos meant two vault
implementations, two build systems, and a seam that went stale twelve minutes
after it was written. The merge eliminated drift by eliminating the seam.

**Retire early, retire visibly.** Every keel retirement was stamped — a
decision artifact with rationale, not a quiet deletion. That discipline made
this postmortem possible and made each retirement reversible in principle. The
desktop compass was tagged (`desktop-archive-2026-06-13`) before removal; six
weeks later, its gems were mapped for revival in a different shape.

## Disposition

- **keel repo:** archive. No code executes from it. Tag `final` at HEAD.
- **kairos repo:** still alive — owns extension, native-host, garmin, kernel.
  Phase D2 moves those into zenborg, then kairos archives too.
- **`~/.keel/` directory:** delete. Symlinks removed, only `.mypy_cache` remains.
