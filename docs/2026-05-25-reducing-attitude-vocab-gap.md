# Reducing-attitude vocab gap

Raw capture — 2026-05-25, during bye-bye-barna planning.

* Zenborg attitudes (BEGINNING/RETURNING/KEEPING/BUILDING/PUSHING/BEING) all describe growth or maintenance.

* No vocab for habit-reduction / tapering / cessation — where the rhythm is a *ceiling*, not a *floor*.

* Today: weed at "weekly 2, aim to reduce toward zero" — encoded only in description text. The system reads it like KEEPING.

* BCTs for reduction are different too: behavior substitution (8.2), restructuring environment (12.1), discrepancy with goal (1.6), identity (13.5).

* Possible attitudes: TAPERING, RELEASING, BOUNDING, CEILING.

* Health logic would also invert: more allocations than rhythm = worse, not better. Wilting = green here.

* Don't shape yet.
